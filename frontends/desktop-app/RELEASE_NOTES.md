# KeeperBMA desktop preview 0.1.0

Native Windows x64 installer and universal Mac disk image (Apple silicon and Intel). These apps open the hosted KeeperBMA website in a dedicated, sandboxed window. An internet connection is required. Website data and available features follow the hosted application; installing this preview does not unlock unfinished business modules or create live multi-device POS synchronization.

Business POS, restaurant ordering, staff kiosk and register handover are demo workflows with fictional temporary data. Real staff authentication, persistent business operations, cross-device synchronization, live payments and payroll remain production work.

These preview installers are unsigned and the Mac app is not notarized. Windows or macOS may require explicit approval for this individual app. Do not disable system-wide protections. No automatic desktop-runtime updater is included; install a later release to update the runtime. Hosted website updates arrive through the website.
