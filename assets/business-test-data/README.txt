KEEPERBMA FICTIONAL TEST DATA

No data has been loaded into a real business. All names, prices, PINs, invoices and events are synthetic. This is not competitor pricing research. Use a dedicated test business.

Import CSV files separately or select the matching worksheet from all_tables.xlsx. Select the matching Import table in CSV / Excel upload. Validate the preview, then confirm import.

Suggested order: stores, role_permissions, staff, devices, categories_100, brands, suppliers, storage_locations, products_100, restaurant_products_100, restaurant_extras, supplier_purchases, stock_movements, inventory_counts, schedules, timesheets, sales, login_events. Restaurant stores are optional. Select Main branch for catalog imports.

The initial retail stock is 50 each. Supplier purchases add 5 each to RT001–RT050. Adjustments add 2 each to RT001–RT020. Counts confirm 57 / 55 / 50 after that order. Re-importing products updates details/prices but preserves stock. Receiving the same supplier invoice twice is rejected. Repeated external_ref rows skip unchanged records.

Staff IDs and device connection codes are generated by the backend. Sample staff PINs are test-only. Do not use them for real employees.

Sales and login-event files import as labelled reference history, not real payments or verified sign-ins. Historical timesheets are closed intervals with source attribution; no payroll payments are made. Supplier receipts change stock but do not record payments.

All times use explicit UTC offsets. 16:00–21:00 UTC on the provided October dates equals 9 AM–2 PM in Los Angeles.
